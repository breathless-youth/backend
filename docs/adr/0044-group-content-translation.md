# ADR-0044: 그룹 원문과 무료 자동 번역을 분리한다

- 상태: 승인된 설계 구현 중
- 날짜: 2026-11-08
- 티켓: BY-1191
- 관련: ADR-0040(그룹), [설계](../superpowers/specs/2026-11-07-by1191-group-translation-design.md)

## 맥락

사용자가 작성한 그룹 제목·소개는 프론트의 고정 문구 번역으로 처리할 수 없다. 한국어·영어·일본어·중국 간체·대만 번체·홍콩 번체를 제공하되, 번역 비용을 발생시키지 않는 것이 우선이다. 매 조회·사용자별 번역은 무료량을 빠르게 소모하며 같은 문구를 중복 전송한다.

## 결정

1. 기존 name/description과 원문 검색을 유지한다. 기존 인증된 그룹 조회 네 곳에 nullable translation 객체를 추가하고 Accept-Language로 대상 언어를 선택한다. 목록은 이름만 번역한다. 프론트는 번역 필드가 null이면 각각 원문을 표시한다.
2. PostgreSQL에 그룹·필드·언어별 성공 결과와 원문 SHA-256을 저장한다. 정상 결과는 만료시키지 않고 원문 해시 변경으로 무효화한다. 이름과 소개는 따로 재사용한다. 최초 배포·수정 시 모든 언어를 선번역하지 않는다.
3. 캐시 미적중은 10초 임차권으로 중복 작업을 줄인다. 그룹 행을 FOR SHARE로 잠근 짧은 트랜잭션에서 현재 원문을 확인한 뒤 캐시를 변경하며, 현재 원문·작업권이 맞을 때만 저장하고, 수정 전 작업의 늦은 완료는 버린다. 프로세스 중단과 외부 호출 사이의 엄밀한 exactly-once는 보장하지 않는다.
4. Google 일반 NMT → Azure Translator F0 → DeepL Developer 무료 잔량 순서로 시도한다. Google 13,000자/일·400,000자/월을 동시에 검사한다. Azure는 서버 보조 제한 2,000,000자/월과 실제 F0 잔량을 따른다. DeepL 신규 Developer의 1,000,000자는 영구 누적 예비분이며 매월 갱신되지 않는다.
5. 외부 호출 전에 공급자 행을 잠그고 문자 수를 영구 예약한다. 동시 인스턴스·재시작에도 유지하며 실패·시간 초과분도 반환하지 않는다. 전송 원문의 Unicode 코드 포인트를 대상 언어·시도별로 센다. 장부 누락·DB 장애·잔량 미확인은 원문 대체로 처리한다.
6. Google 날짜는 America/Los_Angeles, Azure 보조 카운터는 UTC다. 실제 Azure F0 무료 주기가 다르면 공급자 제한이 먼저 적용될 수 있다. 무료 크레딧은 다른 프로젝트/호출자의 소비와 공유될 수 있으므로 공급자 전용 키와 활성화 전 기사용량 반영이 필요하다.
7. 기존 읽기 서비스의 트랜잭션이 끝난 뒤 파사드가 번역을 붙인다. HTTP 대기 예산은 응답당 3초·시도당 최대 2초다. 배열은 50개·5,000 코드 포인트 이하이며 숨은 자동 재시도를 추가하지 않는다. 실패·미처리 필드는 원문으로 표시한다.
8. 기능과 각 공급자는 기본 off다. 키는 서버 설정으로 주입하고 유료 요금제·LLM·맞춤 모델·비동기 batch API를 선택하지 않는다. 새 의존성·공개 번역 API·Security/STOMP 변경은 없다.
9. 대만·홍콩은 캐시 locale을 구분하지만 무료 기본 모델은 같은 표준 번체 코드로 번역한다. 광둥어·지역별 어휘 정확성을 보장하지 않는다. DeepL 대상 언어는 현재 v3 capability API로 확인하며 영어 대상은 en-US다.

## 대안

- 조회마다 번역: 구현은 작지만 무료량·응답 지연·중복 호출 문제로 제외했다.
- 모든 그룹을 모든 언어로 미리 번역: 실제 사용되지 않는 번역까지 소비해 제외했다.
- Redis/번역 SDK: 현재 규모에서는 PostgreSQL 장부와 캐시를 함께 쓰면 충분하여 의존성을 추가하지 않았다.
- 유료 번역/자동 요금제 업그레이드: 사용자 조건에 따라 제외했다.

## 결과와 운영

읽기 API는 번역 실패에 영향을 받지 않고 원문을 제공한다. 첫 캐시 미적중은 HTTP 대기만큼 지연될 수 있으며 다른 요청이 처리 중이면 먼저 원문을 표시한다. 원문과 번역을 함께 읽는 앱 변경이 별도로 필요하다.

Google의 크레딧+초과 과금 구조는 외부 사용·정책 변경까지 포함한 절대적 0원 보장과 다르다. 이번 구현은 이 앱의 허용 호출을 제한한다. 무료 조건을 검증할 수 없으면 공급자를 켜지 않는다. 백엔드 검증 후에만 콘솔 목표 일일 한도 15,000자 적용을 검토한다.

활성화·장부 초기화·원문 대체·품질 평가 절차는 [운영 문서](../runbooks/group-translation.md)에 둔다.
