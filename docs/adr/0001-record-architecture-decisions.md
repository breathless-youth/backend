# ADR-0001: 아키텍처 결정 기록(ADR) 사용

- 상태: 승인
- 날짜: 2026-07-21

## 맥락
AI 도구와 협업하는 프로젝트에서는 "왜 이렇게 했는지"가 코드 밖에 남아야
이후 세션의 AI와 미래의 개발자가 같은 실수를 반복하지 않는다.

## 결정
중요한 기술/설계 결정은 이 폴더에 `NNNN-제목.md` 형식으로 기록한다.
형식: 맥락 → 결정 → 결과(트레이드오프 포함). 5줄 이상 쓸 필요 없음.

## 결과
- Claude Code가 설계 판단 시 이 폴더를 참조할 수 있다
- 결정 번복 시 새 ADR로 대체하고 기존 것은 "폐기됨"으로 표시
