# ADR-0046: 그룹 원문과 무료 자동 번역을 분리한다

- 상태: 승인된 설계 구현 중
- 날짜: 2026-11-08
- 티켓: BY-1191
- 관련: ADR-0040(그룹), [설계](../superpowers/specs/2026-11-07-by1191-group-translation-design.md)

## 맥락

사용자가 작성한 그룹 제목·소개는 프론트의 고정 문구 번역으로 처리할 수 없다. 한국어·영어·일본어·번체 중국어를 제공하되, 번역 비용을 발생시키지 않는 것이 우선이다. 매 조회·사용자별 번역은 무료량을 빠르게 소모하며 같은 문구를 중복 전송한다.

## 결정

1. 기존 name/description과 원문 검색을 유지한다. 기존 인증된 그룹 조회 네 곳에 nullable translation 객체를 추가하고 Accept-Language로 대상 언어를 선택한다. Swagger에 객체/필드의 null을 명시하고 Vary: Accept-Language를 포함한다. 이번 FE 범위는 기존 기기 언어 전달이며 언어 선택 UI는 추가하지 않는다. 목록은 이름만 번역한다. 프론트는 번역 필드가 null이면 각각 원문을 표시한다.
2. PostgreSQL에 그룹·필드·언어별 성공 결과와 원문 SHA-256을 저장한다. 정상 결과는 만료시키지 않고 원문 해시 변경으로 무효화한다. 이름과 소개는 따로 재사용한다. 최초 배포·수정 시 모든 언어를 선번역하지 않는다.
3. 캐시 미적중은 10초 임차권으로 중복 작업을 줄인다. 그룹 행을 FOR SHARE로 잠근 짧은 트랜잭션에서 현재 원문을 확인한 뒤 캐시를 변경하며, 현재 원문·작업권이 맞을 때만 저장하고, 수정 전 작업의 늦은 완료는 버린다. 프로세스 중단과 외부 호출 사이의 엄밀한 exactly-once는 보장하지 않는다.
4. (BY-1294에서 순서 변경) Azure Translator F0 → Google 일반 NMT → DeepL Developer 무료 잔량 순서로 시도한다. Azure F0는 결제 수단이 없어 과금 경로가 없고, Google은 무료분을 넘으면 초과 과금되는 구조라 Azure 무료분을 먼저 쓴다. 처음에는 Google을 먼저 시도했다. Google 13,000자/일·400,000자/월을 동시에 검사한다. Azure는 서버 보조 제한 2,000,000자/월과 실제 F0 잔량을 따른다. DeepL 신규 Developer의 1,000,000자는 영구 누적 예비분이며 매월 갱신되지 않는다.
5. 외부 호출 전에 공급자 행을 잠그고 문자 수를 영구 예약한다. 동시 인스턴스·재시작에도 유지하며 실패·시간 초과분도 반환하지 않는다. 전송 원문의 Unicode 코드 포인트를 대상 언어·시도별로 센다. 장부 누락·DB 장애·잔량 미확인은 원문 대체로 처리한다.
6. Google 날짜는 America/Los_Angeles, Azure 보조 카운터는 UTC다. 실제 Azure F0 무료 주기가 다르면 공급자 제한이 먼저 적용될 수 있다. 무료 크레딧은 다른 프로젝트/호출자의 소비와 공유될 수 있으므로 공급자 전용 키와 활성화 전 기사용량 반영이 필요하다.
7. 기존 읽기 서비스의 트랜잭션이 끝난 뒤 파사드가 번역을 붙인다. HTTP 대기 예산은 응답당 3초·시도당 최대 2초다. 배열은 50개·5,000 코드 포인트 이하이며 숨은 자동 재시도를 추가하지 않는다. 실패·미처리 필드는 원문으로 표시한다.
8. 기능과 각 공급자는 기본 off다. 키는 서버 설정으로 주입하고 유료 요금제·LLM·맞춤 모델·비동기 batch API를 선택하지 않는다. 새 의존성·공개 번역 API·Security/STOMP 변경은 없다.
9. API 언어는 ko/en/ja/zh-TW 네 개다. zh-Hant·대만·홍콩·마카오 별칭은 모두 zh-TW로 정규화해 같은 캐시·무료량을 재사용한다. 간체·미지원 기기는 FE가 영어 화면에 맞춰 en을 보낸다. 광둥어·지역별 어휘 정확성을 보장하지 않는다. DeepL 대상 언어는 현재 v3 capability API로 확인하며 영어 대상은 en-US다.
10. (BY-1216) 원문이 이미 요청 언어로 읽히면 예약·호출·캐시 조회 없이 translation을 생략한다. 공급자 언어 감지는 문자를 보낸 뒤에야 알 수 있어 무료량을 쓰므로, 문자 체계로 확실한 경우만 건너뛴다: 한글이 글자의 과반이고 가나가 없으면 ko, 가나가 있고 가나·한자가 과반이며 한글이 없으면 ja, 글자가 모두 기본 라틴이고 비ASCII 결합 부호가 없으면 en, 글자가 없으면 모든 언어. 다른 문자가 과반인 혼합 문장은 보낸다. zh-TW는 간체 원문을 번체로 바꿔 줄 수 있어 항상 보낸다. 한자만 있는 글·악센트 있는 라틴 글은 판정하지 않고 보낸다. 2026-11-09 로컬 실연동에서 ko 원문 ko 요청·en 원문 en 요청이 사용량의 약 25%를 차지하고 FE에 번역 표시가 붙는 것을 확인해 추가했다.
11. (BY-1301) 그룹장용 신청 목록(`GET /api/groups/{groupId}/applications`)의 신청 소개 글도 같은 방식으로 옮긴다. 각 신청에 nullable `translation`(language, introduction)을 싣고 Vary: Accept-Language를 둔다. 캐시는 신청 행 기준의 별도 테이블 `group_application_translation_cache`(V78, 신청 행 삭제 시 함께 삭제)에 두고, 장부·공급자 순서·같은 언어 건너뛰기·임차권은 그룹 번역과 공유한다. 기한 안에서 답을 기다리는(PENDING·expires_at 이후 아님) 신청만 번역하고 답이 났거나 기한이 지난 신청의 늦은 결과는 버린다. 잠금·예약을 한 트랜잭션에서 하므로 한 요청에서 오래된 신청 20개까지만 옮기고 나머지는 원문이다. 신청 소개 글은 그룹장 한 명만 보는 1~50자 글이라 사용자 간 캐시 재사용이 적지만 글이 짧아 무료량 부담이 작다. 소개 글은 연락처·링크가 막힌 글이며, 그룹 이름·소개처럼 번역 공급자에 원문이 전송된다. 본인이 쓴 글을 보는 내 신청 목록·공개 그룹 상세의 내 신청은 옮기지 않는다.
12. (BY-1409) Azure 응답의 원문 언어 감지 확신도(`detectedLanguage.score`)가 0인 항목은 번역하지 못한 것으로 보고 저장하지 않는다. 그 필드는 같은 요청 안에서 Azure에 다시 보내지 않고 다음 공급자(Google → DeepL)에 넘기며, 모두 못 하면 원문이다. 2026-11-27 문언문 그룹 소개에서 Azure가 언어를 `en`(확신도 0)으로 보고 원문을 거의 그대로(구두점 뒤 공백만 추가) 돌려줬고, 이것이 번역으로 저장돼 "번역됨" 표시와 함께 원문이 나왔다. 원문 언어를 `zh-Hant`나 `lzh`로 지정하면 정상 번역되는 것을 확인했다. "결과가 원문과 같으면 실패"로 판단하지 않는 이유는 이번처럼 공백 하나가 달라질 수 있고, 고유명사뿐인 이름은 번역해도 원문 그대로가 정상이기 때문이다. 이미 저장된 결과는 V92에서 대상 언어 글자(ko 한글·ja 가나·en 라틴)가 하나도 없는 Azure 행만 지운다. zh-TW 대상은 글자로 구별할 수 없어 남긴다. 확신도 0 결과도 Azure 사용량은 쓴다.

## 대안

- 조회마다 번역: 구현은 작지만 무료량·응답 지연·중복 호출 문제로 제외했다.
- 모든 그룹을 모든 언어로 미리 번역: 실제 사용되지 않는 번역까지 소비해 제외했다.
- Redis/번역 SDK: 현재 규모에서는 PostgreSQL 장부와 캐시를 함께 쓰면 충분하여 의존성을 추가하지 않았다.
- 유료 번역/자동 요금제 업그레이드: 사용자 조건에 따라 제외했다.

## 결과와 운영

읽기 API는 번역 실패에 영향을 받지 않고 원문을 제공한다. 첫 캐시 미적중은 HTTP 대기만큼 지연될 수 있으며 다른 요청이 처리 중이면 먼저 원문을 표시한다. 원문과 번역을 함께 읽는 앱 변경이 별도로 필요하다.

Google의 크레딧+초과 과금 구조는 외부 사용·정책 변경까지 포함한 절대적 0원 보장과 다르다. 이번 구현은 이 앱의 허용 호출을 제한한다. 무료 조건을 검증할 수 없으면 공급자를 켜지 않는다. 백엔드 검증 후에만 콘솔 목표 일일 한도 15,000자 적용을 검토한다.

활성화·장부 초기화·원문 대체·품질 평가 절차는 [운영 문서](../runbooks/group-translation.md)에 둔다.
