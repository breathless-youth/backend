# ADR-0027: 인터뷰 모집 대상은 서버가 판정하고, 끄고 켜기는 app_config로 한다

- 상태: 승인
- 날짜: 2026-10-05
- 티켓: BY-833 (스토리 BY-821, 짝 BY-886)
- 명세: `.ai/product/specs/BY-821-인앱-인터뷰-모집.md` §7
- 흡수: BY-376 (공지 조회 API, PR #7 닫힘)

## 맥락

이탈 이유를 듣기 위해 앱 안에서 세 그룹에게 인터뷰 참여를 권한다. 1·2번은 홈의 공지 모달, 3번은 완료 화면 카드로
띄우고 설정에는 신청 행을 둔다. 그룹을 가르려면 세션 기록이 필요하다. 인터뷰가 충분히 모이면 재배포 없이 꺼야 한다.

## 결정

1. **대상(그룹)은 서버가, 언제·얼마나 자주는 앱이 정한다.** 세션 기록이 서버에 있다. 재방문 30분, 모달 2번·7일 간격,
   하루 하나, 다시 보지 않기, 신청 후 중단은 앱 저장소로 판단한다. 업계 인앱 메시지 도구(세그먼트는 서버, 트리거·빈도는
   기기)와 같은 나눔이다.
2. **그룹 기준.** 모두 168시간(`Instant`) 단위라 KST 날짜 변환이 없다. 요청마다 새로 판정한다.
   - 1번: `study_session` 0건이고 진행 중 세션(`active_study_session`)이 없다. 자동 종료 세션도 시작한 세션이다.
   - 2번: 가장 늦은 `ended_at`(자동 종료 포함)이 168시간 이상 전이고, 진행 중 세션이 없다. **진행 중 세션 제외는 명세에
     없던 것이다** — 이미 돌아와 공부 중인 사람에게 "왜 안 돌아왔나"를 묻지 않는다.
   - 3번: 최근 168시간 안에 끝난 완료 세션이 3건 이상. 완료 = 자동 종료가 아니고 순공 10분 이상(스트릭 기준과 같은
     `MIN_STREAK_FOCUS_SEC`).
3. **자정 분할 세션은 `submission_started_at`으로 묶어 1건으로 센다.** 조각들은 루트 제출 시각을 공유한다(V7). 순공은
   합치고, 끝난 시각은 마지막 조각 기준이다. 세션 복구 응답의 집계와 같은 묶음이다. 앞 조각 `ended_at` = 뒤 조각
   `started_at`으로 잇는 방식은 기각: 이미 있는 키를 두고 시각 일치에 기대야 한다.
4. **1·2번은 공지로 내려간다.** 공지에 `audience`(`ALL`·`G1_NOT_STARTED`·`G2_LAPSED`), 배지, 버튼 문구·링크,
   `enabled`를 더하고 `GET /api/notices/active`는 인증을 요구한다. 앱은 `audience`로 source(`g1_revisit`·`g2_return`)를
   정한다. BY-376의 비인증 공개 조회는 배포하지 않는다 — 비회원도 토큰을 받으므로(ADR-0019) 로그인 전 화면이 없다.
5. **`audience`가 `ALL`이 아닌 공지는 인터뷰 공지다.** 인터뷰 전체를 끄면 이 공지들이 빠진다. 공지에 기능 구분 컬럼을
   두는 방식은 기각: 지금 그룹 대상 공지는 인터뷰뿐이다. 그룹 대상 일반 공지가 생기면 다시 본다.
6. **카드·설정은 `GET /api/interview/status`로 따로 내린다.** `{cardEligible, cardUrl, settingsEnabled, settingsUrl}`.
   공지 API에 합치는 방식은 기각: 공지는 인터뷰가 끝나도 남는 범용 API다. 켜져 있어도 링크가 비어 있으면 false다.
7. **끄고 켜기는 `app_config` 키-값 테이블이다.** 운영자가 SQL로 바꾸고 재배포는 없다. 값이 정확히 `'true'`일 때만
   켜진 것으로 보고, 키가 없으면 꺼진 것이다. 캐시하지 않는다. 설정 프로퍼티(`app.<기능>.enabled`)는 기각: 바꾸려면
   재배포해야 한다.

## 결과

- 스키마 V22 `notice`(BY-376의 V9를 다시 매기고 필드 추가), V23 `app_config`(인터뷰 키 5개, 모두 꺼진 채).
- 두 API 모두 기본버전 1(ADR-0015)이다.
- 공지 조회는 활성 인터뷰 공지가 있고 인터뷰가 켜져 있을 때만 그룹을 판정한다. 판정은 쿼리 최대 4개다.
- 운영: 켜기 전에 `interview.card.url`·`interview.settings.url`에 구글폼 링크를 넣고, 1·2번 공지 두 건을 INSERT한다.
