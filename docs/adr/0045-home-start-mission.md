# ADR-0045: 홈 시작 미션을 계정에 저장하고 목표 API를 공유한다

- 상태: 승인
- 날짜: 2026-11-07
- 티켓: BY-1190
- 관련: ADR-0041, ADR-0043, ADR-0044

## 맥락

홈 v3는 기존 과목과 시작일 이후 같은 현지 날짜에 직접 측정한 순공을 두 단계 시작 미션으로 제공한다. 조건을 채우는 일과 사용자가 완료를 확인하는 일은 별개다. 홈의 목표 날짜는 사용자 현지 달력의 자정 기준이지만 플래너는 기존 05시 기준을 유지한다.

## 결정

1. 계정과 미션 버전별로 완료한 단계 수를 보존한다. 현재 단계만 조건을 다시 검사해 확인하고, 같은 단계의 재요청은 상태만 반환한다. 사용자 단위 잠금으로 중복 요청을 직렬화한다.
2. 활성 과목은 기존 과목도 인정한다. `home-v3`는 현지 날짜 2026-11-07부터 하루에 측정 순공 300초를 채우면 조건을 충족한다. 서로 다른 날짜를 합산하지 않고 수동 기록을 제외한다. 확정 세션의 기존 현지 자정 분할 조각을 날짜별로 합산한다. 한 번 조건을 충족한 날짜의 기록은 1단계 확인 전이어도 인정한다.
3. 병합 시 완료 단계는 두 계정 중 더 진행된 값을 택한다. 순공은 병합 후 살아남은 원본 세션에서 다시 계산하며 기존 기록의 겹침 제거 규칙을 따른다. 확인이 끝난 단계는 과목 삭제나 기록 편집으로 취소하지 않는다.
4. 홈은 기존 날짜별 목표 PUT에 `calendar=HOME`과 기기 시간대를 보내 달력상 오늘과 과거 날짜를 수정한다. 자정 이전 요청이 실패하거나 응답이 유실돼도 같은 날짜로 재시도할 수 있다. 기본 호출의 플래너 05시 미래 날짜 제한은 유지하고, 조회와 기본 목표도 기존 API를 공유한다. 목표는 0~86400초를 1초 단위로 저장한다.

## 결과

- 앱 재설치나 날짜 변경으로 미션이 초기화되지 않는다. 새 미션은 버전과 시작 날짜를 함께 정해 배포해야 한다.
- 자정을 걸친 측정은 기존 분할값을 쓰므로 날짜별 순공은 비례 배분 추정치다. 정확한 구간별 순공이 필요하면 측정 계약을 확장해야 한다.
- 운영값과 병합 규칙은 [운영 문서](../runbooks/home-mission.md)를 따른다.
