# 홈 시작 미션 운영 (BY-1190)

미션 버전은 `home-v3`, 인정 시작일은 2026-11-07이다. `app.home-mission.starts-on`으로 시작 날짜를 지정할 수 있으나 배포 환경 간 값을 일치시키고 시작 후에는 변경하지 않는다. 다른 기준의 새 미션은 버전과 저장 규칙을 별도로 설계해야 한다.

시작일 이후 같은 현지 날짜의 확정 측정 순공을 합산해 하루 300초 이상인 날짜가 있으면 조건을 충족한다. 서로 다른 날짜나 수동 기록은 합산하지 않는다. 자정을 걸친 측정은 기존에 현지 날짜별로 분할한 조각을 사용하며, 그 분할값은 기존 비례 배분 방식의 추정치다. 완료 확인 후 조건이 바뀌어도 완료는 유지된다.

계정 전환은 사용자 ID를 유지한다. 기존 계정으로 병합할 때 버전별 더 앞선 완료 단계를 보존한다. 인정 시간은 병합 후 남은 측정 세션을 다시 합산한다. 세션 병합의 기존 중복·겹침 제거 규칙을 따른다. 계정 탈퇴 시 완료 상태도 삭제한다.
