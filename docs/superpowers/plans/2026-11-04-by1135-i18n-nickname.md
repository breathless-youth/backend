# 다국어 닉네임 구현 계획 (BY-1135)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 기본 닉네임을 휴대폰 언어별 `꾸미는 말 + 동물`로 주고, 닉네임 규칙을 다국어(1글자~40칸)로 넓히고, 무료 금칙어로 욕설·사칭을 막는다.

**Architecture:** 닉네임 규칙·단어 목록·금칙어는 모두 `project.study.user.nickname`의 정적 도구(리소스 파일을 클래스 로딩 때 읽음)로 둔다.
`UserService`가 가입 때 언어를 골라 목록에서 뽑고, 프로필 수정 때 금칙어를 본다. 대소문자 무시 유일성은 DB 함수 인덱스가 강제한다.

**Tech Stack:** Spring Boot 4.1, Java 25, PostgreSQL, Flyway, JUnit 5 + AssertJ, Testcontainers, `MockMvcTester`

**Spec:** `docs/superpowers/specs/2026-11-04-by1135-i18n-nickname-design.md` (단어 목록: 같은 폴더 `2026-11-04-by1135-nickname-lists/*.json`)

## Global Constraints

- 새 의존성 없음. 필요해지면 멈추고 사용자에게 이유를 설명해 승인받는다.
- 스키마는 Flyway로만. 이 작업의 번호 레인은 **V60~64**(ADR-0041 레인 규칙). ADR 번호는 **0044**.
- 닉네임 상한 **40칸**, 하한 **1글자**. 한글 음절·히라가나·가타카나·`ー`·한자·`々`·이모지 = 2칸, 나머지 허용 글자 = 1칸.
- 기본 닉네임 조합은 어느 언어든 **30칸 이하**.
- 정규화는 닉네임에만 **NFKC** + 앞뒤 공백 제거. 공용 `Graphemes.normalize`(NFC)는 다른 글자 필드가 쓰므로 바꾸지 않는다.
- 외국어 단어는 JSON 그대로 옮긴다(고치려면 사용자에게 먼저 묻는다).
- 금칙어 목록에 정치 용어를 넣지 않는다(욕설·성적 표현·혐오·사칭만). 출처 라이선스는 상업적 사용 가능(CC BY·MIT·퍼블릭 도메인)이어야 하고 `NOTICE.md`에 적는다.
- 연락처(`ContactDetector`)는 닉네임에 적용하지 않는다. 해외 앱 이름 사칭은 이번 범위 밖.
- 커밋은 **모든 작업이 끝나고 Codex 리뷰·퀴즈를 통과한 뒤**에 한다(CLAUDE.md 퀴즈 게이트). 그 전까지 각 작업은 테스트 통과까지만.
- API 테스트는 `MockMvcTester`, 통합 테스트는 `TestcontainersConfiguration` import. 실패 테스트 삭제·@Disabled 금지.

## Review Focus

1. **대소문자·전각만 다른 닉네임** (`Otter` / `otter` / `ＯＴＴＥＲ`): 두 번째부터 409여야 한다 → Task 3 테스트.
2. **바꾸지 않은 닉네임을 그대로 다시 보내는 PATCH** (프론트가 폼 전체를 보냄): `nickname_auto`가 true로 남고, 금칙어 검사도 하지 않는다 → Task 3·5 테스트.
3. **언어 태그 변형** (`zh_TW`, `ZH-hant-hk`, `en-US`, `""`, `xx`, `null`): 표대로 매핑되고 예외 없이 `en`/`ko`로 떨어진다 → Task 2 테스트.
4. **정상 단어 속 금칙어** (`Scunthorpe`, `assassin`, `Grape`, `시발점`, `포메라니안`)와 **모든 기본 닉네임 6만 개**: 막히지 않는다 → Task 5 테스트.
5. **40칸 경계** (한글 20자 = 통과, 한글 20자 + `a` = 거부, 이모지 20개 = 통과, 영문 41자 = 거부): → Task 1 테스트.
